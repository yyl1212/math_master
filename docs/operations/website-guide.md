# 网站功能与使用方法

Math Master 围绕“按主题查找知识、阅读、记录笔记、完成学习、按需复习”组织。分类采用63个一级主题、534个二级主题、4969个具体主题；503个辅助分类和534个其他兜底节点单列，完整目录共6603个节点。目录节点数量不等于已经审核发布的知识点数量，空主题会显示暂无内容。

本说明对应主题学习重构完成后的功能。代码交付、正式内容审核、生产迁移和网站部署是不同步骤，生产入口以实际启用状态为准。

## 开始学习

1. 在页面顶部选择“中文”或“English”，选择会在本浏览器保存。打开 `/register` 创建账户，随后在 `/login` 登录；普通账户进入“我的学习”，临时密码账户先进入“账户”修改密码。
2. 在“知识地图”按三级主题浏览或搜索知识标题和分类代码。打开主题详情，选择已发布知识点；没有内容的主题可继续查看目录。
3. 打开知识阅读页，阅读定义、条件、讲解、证明、来源和相关知识。页面完成账户核验后开始记录学习；匿名浏览不产生个人记录。
4. 在私人笔记框记录理解、问题和公式，点击保存。笔记只属于本人，管理员和审核者不能因角色读取。支持受限Markdown与安全公式，最多16000个Unicode字符且64KiB，不支持图片或附件。
5. 阅读完成后点击“完成学习”。重复阅读仍保持完成；需要回顾时点击“开始复习”，回顾后点击“结束复习”。
6. 回到“我的学习”查看主题进度、继续学习或检索已学知识。打开“学习历史”按知识、主题、日期或动作筛选时间线。

## 学习状态与进度

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 未学习 | 没有明确学习记录 | 打开知识并开始阅读 |
| 学习中 | 已开始，尚未明确完成 | 继续阅读、记笔记或完成学习 |
| 已完成 | 有明确完成事实 | 重读或主动开始复习 |
| 复习中 | 已完成知识正在一轮复习 | 结束该轮复习，回到已完成 |

主题进度按当前公开可用知识去重计算。跨主题引用不会重复增加同一祖先主题分母，复习不会降低完成率。没有可用知识时显示暂无内容。分类移动只改变归属；材料升级显示需要回顾的提示；撤回知识不进入当前分母，私人笔记和学习历史仍保留。

时间线保存开始、明确完成、每轮复习开始和结束、笔记保存与删除，以及有来源的旧学习事件。普通重读更新最近阅读时间，不把页面停留或后台挂机作为学习时长。历史日期按UTC解释，事件保留当时材料版本。

## 页面与职责

| 页面 | 主要用途 | 使用者 |
| --- | --- | --- |
| 学习首页 `/` | 了解目录、建设状态并进入主题 | 所有人 |
| 知识地图 `/knowledge` | 搜索和浏览三级主题、定位知识 | 所有人 |
| 板块详情 `/topics/{id}`（旧板块链接 `/domains/{id}` 仍可访问） | 查看主题路径、子主题和已发布知识；旧板块入口按明确映射跳转 | 所有人 |
| 知识阅读 `/knowledge/{id}` | 阅读正式材料，登录后学习与记笔记 | 所有人；私有控件仅本人 |
| 我的学习 `/learn` | 查看进度、继续学习、复习检索与回顾提醒 | 登录用户 |
| 学习历史 `/learning-history` | 检索本人知识学习时间线及明确标识的旧档案 | 登录用户 |
| 我的反馈 `/feedback` | 查看本人报告、补充信息、跟踪处理状态 | 登录用户 |
| 账户 `/account` | 修改密码、退出当前或全部会话 | 登录用户 |
| 内容工作区 `/editor` | 编写知识、讲解、来源、原创素材和主题归属 | 编辑人员 |
| 内容审核 `/review` | 独立复核冻结材料与主题归属，批准或退回 | 审核人员 |
| 发布管理 `/admin/publications` | 准备和激活配对发布，进行永久撤回 | 管理员 |
| 反馈与纠错后台 `/review/feedback`、`/review/corrections` | 处理网站和知识报告，定位修订、撤回及替代版本，查阅受保护旧案件 | 审核或管理人员 |
| 人员管理 `/admin/users` | 调整岗位、人工验证归属后重置临时密码 | 管理员 |

后台入口按账户岗位显示。反馈处理不能替代数学审核；分类正确也不等于内容已经批准。私人笔记不会进入公开内容包、反馈列表或分类导出。

## 复习与异常处理

在“我的学习”进入复习检索，按标题、主题和状态查找本人已学知识。尚未完成的知识继续学习；已完成的知识可以开始复习。材料更新后重新阅读当前版本，再主动确认完成或结束复习，已确认的更新从待回顾区域移除，变化事实和旧完成时间及旧版本记录仍保留。

笔记需要明确保存。切换界面语言保留未保存输入；离开页面前会提示。两个标签页同时编辑可能发生修订冲突，此时保留当前输入，先读取最新笔记，再选择采用或重新保存。删除会清空正文并保留不含文本的修订记录，历史事件不保存文本副本。

请求超时后只点击“重试同一请求”确认原操作，不自动重复提交。更换账户、撤销会话或强制改密后私有区域重新核验身份，原账户输入不进入新账户页面。知识撤回后，从“我的学习”仍可查看或编辑本人笔记，公开正文不再提供。

## 提交反馈与内容修订

知识页的反馈入口绑定准确知识或讲解版本；主题分类问题使用网站反馈并注明分类代码与版本。填写类别、标题、位置和问题说明，在“我的反馈”追踪新建、处理中、等待补充、已解决或已关闭状态。处理人员可以请求补充或记录解决依据，原报告及后续讨论形成时间线。

编辑人员在“内容工作区”创建知识草稿或打开既有草稿，填写知识正文、讲解、相关知识、准确来源和原创素材。主题归属使用当前分类中的准确主题ID，保存并核对侧车校验结果；分类归属与数学正文分别冻结，但一起经过审核和配对发布。保存后先校验，再送审。审核人员复核冻结内容、来源、证明和主题归属。管理员准备知识与分类归属的配对发布，核对版本后激活。公开修订始终经过此流程；将工单设为已解决不会直接发布材料。

旧路线、练习、检测和题库新写功能在正式切换后停用，旧链接显示说明并提供主题学习入口；旧答案和成绩保留在受保护档案，不会转换成新完成率。旧检测通过、诊断或解锁不能替代明确完成事件。

## 后台操作顺序

1. **内容工作区**：编辑自己的草稿，预览阅读效果，补足条件、证明、来源和素材。校验通过后送审；被退回时按说明创建修订，再次送审。topics模式下旧路线字段只读。
2. **内容审核**：查看冻结的准确版本、来源和主题归属，逐项核验数学、解释、关系、来源与插图，批准或说明退回理由。审核必须遵守作者独立性，不能把目录整理替代内容正确性审核。
3. **发布管理**：从已批准提交准备候选发布，查看差异和当前知识/分类配对，复核后明确激活。准备不会立即公开；撤回须给出理由并明确确认，撤回知识不再进入公开学习分母。
4. **反馈与纠错后台**：打开工单核对来源版本，进入处理中；需要信息时请求补充。需要修订的知识回到正常编写、审核和发布流程，完成后记录解决依据。已有旧判分任务和受保护案件可查阅，正式切换后不再新建判分纠错计划。
5. **人员管理**：按实际职责设置学习、编辑、审核或管理岗位；调整后相关页面重新核验权限。密码重置须先人工验证账户归属，用户用临时密码登录后先改密，再进入学习。

公开目录尚无对应已批准内容时会显示暂无内容；可以继续浏览分类或提交建设反馈。没有岗位的账户不会获得内容审核、发布或人员管理能力。

旧题目保护结构暂不可用时，混合反馈列表只分页展示网站和知识工单；受限的旧练习/检测工单保留在数据库，保护恢复后重新可见。其正文、讨论和直接读取仍拒绝交付，不把它们标成已撤回或已解决。

## 实施裁定与边界

1. 子计划标题改为 `Task N`，匹配技能提取器，任务内容不变；代价：文档标题调整。
2. 共用只接收固定 SQL 片段的页码组合器，各领域保留筛选与投影；避免重复窗口/快照逻辑；代价：需要真实 SQL 回归与独立审查，均已执行。
3. 语言覆盖清单精确登记新具名浏览器场景；原工具只枚举旧场景；代价：扩展库存枚举，原校验逻辑保持。
4. 页码 scene 和夹具同文件，沿用 harness 鉴权，避免无逻辑转发；代价：控制仍由原 harness 统一保护，生产不引用 e2etest。
5. 测试驱动触发真实 SQL 除零中止；新增故障触发器会被原结构门禁先拒绝；代价：故障驱动仅覆盖隔离测试库。
6. 失败项重读仍受新 transport 的1MiB上限；避免读取整批正文及绕过边界；代价：极大正文失败项须用原单条编辑及管理列表明确重新选择。
7. 按任务使用事务局部标记去重计数检查，每次 job/item 写入均使缓存失效；10001条创建由7.6秒降至134毫秒，仍保留8秒业务截止与真实约束；代价：新增触发器路径需要独立审查，已执行，摘要固定为 `b709ad5e16cd5e3f124a8135c323d0d2`。

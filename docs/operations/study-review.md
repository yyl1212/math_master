# 复习功能优化与知识点默写

本阶段优先服务个人持续学习。复习对象为当前已发布、本人已经完成首次学习的知识点；私人笔记和审批分享继续使用原流程。默写采用“自己作答→主动揭示原知识内容→自行比对→自评”，系统不进行数学判分，不计算文本相似度，也不生成参考答案。

## 使用流程

1. 从“我的学习”进入 `/learn/review`，查看未完成、内容更新、到期、未安排和未来安排五类项目。可按主题和标题筛选，每页默认20项、最多50项；一项知识只计入一个最高优先级分类。
2. 选择阅读复习、陈述默写或证明默写。无证明的知识不提供证明默写；证明题干包含原陈述、条件、适用范围、系统和公式，参考证明在答完并主动比对后提供。
3. 默写支持原数学格式按钮和自己的公式预览。保存草稿是明确操作；未保存时离开会提示，取消后保留输入和焦点。答案最多16000个Unicode码点，不截断输入，不写入URL、浏览器存储或日志。
4. 点击“答完，查看参考”后冻结作答，自行比对原内容。未作答可以明确提交空答，该次只允许“忘记”。冻结后不能修改作答。
5. 按“忘记／不熟／熟悉”自评后，服务器保存安排；历史页 `/learn/review/history` 同时保留当次自评的安排和当前最新安排。

| 自评 | 阶段及下次时间 |
| --- | --- |
| 忘记 | 回到阶段0，服务器完成时刻后600秒 |
| 不熟 | 有效阶段减1，最低0，完成时刻后86400秒 |
| 熟悉 | 阶段递增至5，分别间隔1、3、7、14、30天 |

无安排或知识内容更新时，有效阶段统一按0计算。同一内容在到期前选“熟悉”保持原阶段和原到期时刻；评分历史仍记录本次操作。时间按UTC经过秒数计算，界面按用户语言显示。

知识改版后，旧题干和参考都隐藏，自己的草稿或冻结答案保留；需要明确放弃旧会话并重新开始。知识下架后也隐藏官方内容。放弃只结束本模块会话，不伪造原学习流程的完成事实，不自动复制答案。

## 数据与接口

迁移 `00015_study_review.sql` 新增会话、固定参考快照、安排、事件及幂等回执五张表。固定参考、事件和回执不可改写；同一用户/知识最多一个活动会话，同一个原复习周期最多一次自评。

`/api/v3/study/review` 提供概览、队列、历史、会话及明确的开始、草稿、比对、自评、放弃命令。所有私人读取和写入检查本人身份，管理员不能读取别人的作答。写命令包含CSRF、幂等键和预期序列，返回无正文回执后再读取当前状态。请求结果未知时只确认原请求；已确认写入但读取失败时只重读，避免重复安排。

原手动开始/完成复习继续可用。原入口先完成当前周期时，新自评不会重复产生原完成事件；原入口已经开始下一周期时，旧会话不能结束新周期。原首次完成时刻、四个学习状态、六类学习事件和笔记分享规则保持。

请求上限128KiB，响应上限1MiB，HTTP/事务8秒、锁1秒、Next10秒。题干及参考原文本合计最多524288字节；编码后材料最多589824字节，发起前检查答案和元数据的组合预算。原知识源仍限制标题512码点，私人模块为更宽的1024码点/4096字节标题包络进行防御性预算验证。列表不包含作答或参考正文。

## 发布与恢复

本阶段MR通过后，正式部署使用批准的准确合并提交，先执行现有一致性备份和恢复演练。迁移1—14、原managed摘要 `f81857f4af9a3be336d85f279578df8b` 和sharing摘要 `2179de9c9ef5b78ec31debb6d5f4fb6c` 保持；新模块摘要独立为 `2da021ff441d7e514c792890c9f76a3c`。

Go、Next和公网入口成组发布。`GET /api/v3/study/review/health` 只返回 `capability`、`schemaReady` 两个布尔值；原 `/readyz` 形状保持。部署依次核对Go、Next代理和可信HTTPS入口，任一健康缺失或不完整均拒绝进入下一步。15版必须显式具备 `studyReview` 及全部原能力，16版拒绝。数据库已经到15时，14版代码不能直接回退运行。

只有五张新表全部为空时迁移Down才允许；已有会话、作答、安排、事件或回执时拒绝Down。故障时保留数据库和诊断状态，按现有恢复流程处理，禁止删除数据或关闭结构检查。恢复14版备份并升级15时，应逐表核对原业务表和原序列，五张新表初始为空；恢复已有15版数据时，五张新表及原全部业务表、序列必须一并核对。

## 验证和现场验收

所有测试使用专用随机隔离库，`CGO_ENABLED=0`，每条验证命令最多540秒、Go测试最多5分钟。新增后端及前端专用 `study_review_verify` 作业，原作业命令、预算和浏览器尺度保持。真实恢复测试通过 `STUDY_REVIEW_RESTORE_CONTAINER` 指定自有PostgreSQL17.11测试服务，并只删除本次随机标记的恢复容器。

现场用测试账号完成阅读复习、陈述和证明默写、保存/刷新/比对、自评及历史检查；再验证跨标签冲突、未确认请求、注销/改密清理、知识改版/下架、窄屏与中文/英文切换。自评历史与原复习周期应逐项对应，公开健康和所有列表不应包含私人作答。

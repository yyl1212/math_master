# P6b 全量内容复核清单

本阶段提供离线准备工具，不能代替真实数学、出处和许可复核。初始范围为 30 知识、30 单元、1 路线、9 原创 SVG、24 模板、450 固定题、384 参数实例、30 blueprint；共 958 个对象及 205 条所选来源记录。64 个来源映射涉及 51 条记录，其余 154 条也保留登记。全部 834 个实例均需复核，不抽样。五项实际证明逐项复算。

| 对象 | 必需复核 |
| --- | --- |
| 知识 | 陈述、适用条件、前置、学习目标；有 proof 时另核对证明 |
| 单元 | 多角度解释、例题、反例及边界 |
| 路线 | 准确版本闭包、前置顺序与学习顺序 |
| 图 | 数学正确性、无障碍、桌面及移动视口、权利依据 |
| 模板 | 题意、参数域与排除条件、全部生成、唯一答案、解析、目标 |
| 实例 | 每一题面/选项/答案/解析和目标；派生题关联准确模板 SHA 和参数 |
| blueprint | 准确知识/题目绑定、核心目标语义、五题覆盖、练习曝光后的覆盖 |
| 来源 | 出处定位、版本条件、实际用途、许可与引用依据；未引用记录未知字段留空 |

初始 `review-register.json` 和 `register/` 不作编辑。保留整个原复核包，在新 `review-register.final.json` 与 `register-final/` 副本完成审阅；最终根记录各分片实际 SHA256，每片最多 100 行。`manifestSHA256` 始终绑定原 `review-manifest.json` 原字节。不得删除 1163 行或必需检查。

每项初始 `unreviewed`。`passed` 须有具体核对依据 `basis` 和本人 `reviewerRef`；对象的 reviewerRef 与实际送审批准 reviewer ID 一致，来源的 reviewerRef 与 ReleaseContext.attestedBy 一致。`returned` 保存准确问题位置 `issue`。未核验、空依据、空人员引用及 returned 均不能形成就绪证据。相同来源许可材料可以共享，数学对象条件与用途必须逐项核对。AI_checked、CC0/CC-BY-SA 标签及机器题目校验均只是待核验信息。

正文、条件、证明、目标、参数和完整选项/答案/解析以 JSON 文本展示在转义后的惰性 `<pre>` 中；URL 与代码片段只作为数据。图引用仅指向包内原创 SVG。需要改正时追加准确版本、相关引用及来源映射，用明确新清单重新 prepare；旧记录及旧批准不复用。

正式操作前落实 R1 实际人员与非生产环境，R2 全量数学/来源复核及正常知识送审，R3 正常双 head 发布及知情纠错，R4 最终八检查与一致只读 content-audit。技术夹具必须保留 fixtureOnly=true，不能称作正式 accepted。

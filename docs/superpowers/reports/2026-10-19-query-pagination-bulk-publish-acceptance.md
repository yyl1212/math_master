## 实施裁定与边界

1. 子计划标题改为 `Task N` 以匹配技能提取器，任务内容不变；代价仅为文档标题变化。
2. 领域各自保留固定 SQL 条件与投影，共用内部页码窗口查询组合器，不接受用户表名或排序；代价是组合器需要真实SQL及独立审查。
3. 语言覆盖清单精确纳入两个新具名浏览器场景，不放宽其字段与库存校验。
4. 页码 scene 与原 harness 统一鉴权，未创建无逻辑的单独控制转发文件；生产代码不引用 e2etest。
5. 故障注入通过测试驱动触发真实SQL中止；添加故障触发器会先被原结构门禁正确拦截。
6. 大清单约束以事务局部标记避免对每条已排队事件重复扫描；每次 job/item 写入会清标记，最终计数仍受约束。新摘要固定为 `b709ad5e16cd5e3f124a8135c323d0d2`；原三套摘要未变。
7. 失败项重新检查采用新 transport 的1MiB读取上限，超过时暂停，须用原单条编辑及管理列表重新选择；不会静默换令牌。

浏览器取消 RSC 请求时，Next.js 测试服务器记录过 `The destination stream closed early`；相关真实操作及断言均通过，未把日志当成发布结果。正式部署仍需按项目发布流程执行迁移、备份和环境验收。

# 学习与测评操作说明

P4b 接在原账户、内容审核和可信题库之后。正式数学内容仍须独立核验和批准；本阶段的容量、浏览器数据是原创技术夹具，不能作为正式课程内容。

## 启用与恢复

服务启动不自动迁移数据库。准备备份、在维护窗口核对目标数据库后，由操作人员显式执行既有迁移程序：

```sh
CGO_ENABLED=0 GOTOOLCHAIN=go1.27.1 go -C backend build -o bin/migrate ./cmd/migrate
./backend/bin/migrate --dir db/migrations up
```

新增迁移为 `00006_learning_assessment.sql`，新增16张学习实体表及约束。旧00001—00005迁移保持原字节。`goose_db_version` 中的 `learning_enabled` 是迁移启用记录；回退00006后保留该记录，不能手工删除它来绕过答案曝光保护。

从未启用学习层的数据库保留原题库交付方式。曾启用但学习表缺失、部分缺失或回退后，学习服务返回 `LEARNING_NOT_CONFIGURED`，相关题库答案交付也必须拒绝。恢复方式是检查迁移日志和完整性、重新正确应用00006及前置迁移；不能通过删标记或手动补分恢复。不要将真实服务器、账户或资料文件用于测试。本次开发没有执行生产迁移或部署。

## 用户动作及进度含义

英文页面为 `/learn`、`/learning-history`、`/knowledge/{id}`、`/paths/{id}`、`/practice/{id}`、`/assessments/{id}` 和其 `/result` 页。中文知识术语保留。

- 浏览讲解不产生个人学习记录。`Start learning` 和 `Mark as learned` 分别记录开始和明确完成。
- `read`、`passed`、`historically unlocked` 分别对应有效阅读完成、有效检测通过和曾经实际授予的解锁，不能互相代替。
- 普通推进要求全部准确前置知识版本有“完成学习＋有效通过”证据；有效诊断资格可替代该前置要求。诊断只授予被测目标，不伪造其他前置的学习。
- 路线通过 `Join route` 明确加入，固定版本和节点分母。撤回节点仍保留在分母中并显示 `Unavailable`。新版路线需要用户主动加入。
- `Unlearned`、`Learning`、`Learned`、`Needs review`、`Mastered` 是后端提供的当前状态。最新复习失败可显示需要回顾；历史解锁记录保留。

完成学习依据当前准确知识、讲解和素材集合核验。材料变更后可能需要重新明确完成，第一次完成时间仍保留。有效通过数量与阅读资格是不同指标；诊断通过不自动补写阅读记录。

## 练习与五题测评

单题练习可用于尚未解锁的知识，也不要求存在测评蓝图。一次有效作答或 `Reveal answer` 会结束练习；揭示答案没有分数和资格。每账户最多一个进行中的单题练习。练习选择会排除当前正式检测的五题，历史练习答案的读取也不能穿透当前正式检测的重合保护。

正式检测每次五个不同实例，覆盖全部核心目标，至少四题正确通过。节点、诊断、复习共用同一选择和评分规则。数值使用精确有理数；原输入字符串保留。数值最多128个字符，分子分母最多256位。五项格式全部验证后一次判分，非法格式不能写部分答案或分数；未作答必须明确选择 `Skip`。

检测题来自实际发布并独立批准的有限实例，不在用户请求中动态生成题。题面页仅包含安全题面；答案和解析仅在合法终态结果中显示。每账户最多一个进行中的正式检测，有效区间为创建时刻起24小时，界面展示绝对到期时间。

创建前30分钟内的答案曝光会排除准确实例或其准确模板的生成族。账户全局最近一次已提交检测的五题也排除，跨蓝图、跨模式，包含 `affected`；该排除不按时间失效。若固定题源只有五题，需增加实际审核的新题源才能继续，不能删除历史记录伪造可用性。`retryAt` 仅在冷却结束后确实能组成五题覆盖时提供。

## 曝光、历史和撤回

所有可能交付题库答案的草稿、校验、冻结提交、复核、导出、实例预览、单题终态及检测结果入口，在实际交付前记录准确曝光。相同幂等键重放也重新进行当前授权、撤回投影和曝光记录。曝光写入失败，必须拒绝交付答案。

创建后出现相关答案曝光、准确知识更新或永久撤回，会使本次提交成为 `affected`，分数和通过字段为 `null`，并且不授予新资格。普通题库替换保留合法旧批准事实；永久撤回即时限制对应旧证据。另一份仍有效的通过证据可以继续支撑当前资格。

原始五项作答及原分数不可改写。提交后撤回会使结果成为受限历史，隐藏受影响题的答案和解析，保留原始分数事实；不能把受限证据继续当作当前资格。历史知识页只展示自有记录摘要和当前讲解入口，不恢复已经撤回的旧讲解。

私有素材入口为 `/api/v1/learning/assets/{attemptId}/{sha}`，要求尝试归属于当前用户、素材属于其固定依赖且当前未受永久撤回限制。校验真实SVG、SHA和1MiB上限，无公开素材地址回退。其他用户的尝试、结果和素材统一不可读取。

## 幂等、取消与故障

写操作使用当前账户的会话、CSRF证明、准确发布头与UUID幂等键。未收到确认时，前端保留冻结输入和原键，只通过 `Retry same request` 主动重试。编辑输入后使用新键。切换账户或卸载页面会清除待确认命令，旧响应不能更新新账户的页面。未提交草稿只存在组件内存，刷新不会从浏览器存储自动恢复或自动提交。

学习动作的10秒截止从点击开始，包含身份准备及后续请求；取消、换账户和卸载页都终止当前等待。前端取消或超时不代表服务器已经回滚。应查询自有尝试或手动重放原命令确认状态，不要把按钮禁用解释为提交已取消。`ASSESSMENT_ACTIVE` 提供安全的继续入口；`ASSESSMENT_NOT_READY` 显示题源/覆盖/冷却原因，不显示零分。

错误响应不含SQL、凭据、私有题库内容或服务内部异常。JSON请求为8KiB上限，完整JSON响应4MiB上限，素材1MiB上限。服务事务维持8秒、数据库锁等待1秒；内容、题库和创建练习/检测共用原有两个重操作槽，不增设学习专属配额。

运维不得修改用户持续更新的 `Knowledge_JSON` 原资料、真实学习记录或服务器来构造容量数据。P5 的纠错反馈和自动重评另行设计；本阶段没有生产部署、自动迁移、自动重评或正式数学内容批准。

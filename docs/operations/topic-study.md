# 个人主题学习操作与边界

阶段 B 依赖分类与配对发布。普通登录进入 `/learn`，临时密码仍进入 `/account` 改密。页面根据数据库模式选择体验，部署和迁移不会自动切换真实模式。

用户从知识地图、主题进度或知识列表直接打开知识点。SSR 与预加载只读；实际阅读在客户端核验账户后发送开始命令。未学习变为学习中，主动完成后成为已完成。普通重读不取消完成；主动复习后成为复习中，结束后回到已完成。同键和语义重复不增加状态事件。

进度按当前公开可用知识去重，跨主题引用不重复计算祖先。复习保留完成事实；零内容显示暂无内容。新增与移出以本人首次原生学习行为对应目录为基线，只读计算。材料升级、分类移动和撤回不清除个人事实。

私人笔记只属于本人，管理员不因角色获得读取权限。支持受限 Markdown 和安全公式，不支持 HTML、图片、附件或危险宏。最多16000个 Unicode 标量且64KiB，保存请求128KiB。保存和删除核验修订号；冲突保留输入，先读最新笔记再选择内容。删除清正文并保留修订墓碑，事件和回执不复制文本。知识撤回后本人仍可在我的学习查看和编辑笔记。

历史按知识、当前主题、UTC日期和事件类型检索。事件保存当时知识引用、分类版本及发布指针；旧来源没有当时分类时保持null。普通重读只更新最近阅读，不计算停留成绩。

Go总截止8秒、锁等待1秒，Next与客户端10秒包含身份准备。普通列表默认20最多100，历史默认20最多50；响应2MiB。未确认命令只能主动重试同一输入与键。换账户、强制改密或撤销会话清除私人子树，晚到响应不应用到新身份。

00011留下不可清除的永久能力标记。只有空表可回退到00010；任一学习数据存在时Down拒绝。结构或保护缺失时拒绝操作，不能删标记或清历史恢复旧行为。迁入和旧写退出由阶段 C 完成。

回归仅使用随机PostgreSQL库及原创数学、笔记夹具。study_control仅注册在token/loopback测试harness，生产server不依赖它。真实课程未批量批准、合并或部署。

## 开发裁决与验证记录

- Ruling: B2消费A6真实成对fixture而非A4裸分类fixture — 新知识可用性必须基于发布证据 — 若错误会让未发布内容可学习，真实head/撤回与版本回归覆盖。

- Ruling: NoteView/Receipt由服务端返回actorId，输入不接受actorId — 明确本人归属并拒绝换账户晚到响应，仍不在回执保存正文 — 若客户端漏核验B6真实账户边界回归应失败。

- Ruling: B7提前补安全体验模式读取及SSR消费者接口 — 不能按study_enabled提前切换，A已以RED→GREEN保证安装能力仍legacy — 若错误会提前替换旧界面，legacy/topics真实场景和C退役回归覆盖。

- Ruling: 任务标题增加Task N工具标记，正文和步骤保持 — Native提取器只认英文数字标题 — 若定位有误逐B1—B8核对brief与计划。

- Ruling: 撤销 B1 补 KnowledgeSet 的先前裁决，复用现有 A 合同 — 完整编译发现重复类型，已核对后移除新增重复；不是行为红灯 — 若定位错误会导致编译失败，目标Go整包重新验证。

- Ruling: 历史事件taxonomyVersionId允许旧来源为null，新原生事件必须准确分类版本且无legacy来源ID — 旧started/completed事件产生时未有新分类，不能把迁入时分类冒充当时归属；TS拒绝错误原生/接受明确旧来源已观察行为RED — 若投影错误会误标历史主题，C3准确来源/时间迁入必须核验。

- Ruling: B2提前增加B8的harness显式5表重置清单 — 原账户及学习真实fixture已RED，随机空库诊断SQLSTATE 0A000证明新FK阻止旧TRUNCATE；不使用CASCADE，仍仅OpenVerified随机库 — 若漏表真实场景明确失败，不影响真实库。

- Ruling: 读预检使用独立transport Read操作，状态机仍只接受六个业务动作 — 具名StudyPreflight还要服务GET；账户预算及本人权限与既有规则一致 — 若误用于状态转换ApplyState返回Invalid，HTTP分派固定路由验证。

- Ruling: 材料变更冲突后允许同一reviewId以刷新后准确知识/head显式确认完成，保留原开始事件版本 — 计划要求复习可恢复，不能把用户永久卡在reviewing或静默认可旧请求；旧引用必须409，准确新版才可完成 — 若误确认会把未读新版当作复习，因此界面须明确显示当前材料并只在用户主动完成时提交。

- Ruling: materialChanged比较最近明确完成或复习结束的准确引用，CompletedRef仍保留原完成依据 — 用户已经主动回顾新版时不应继续显示未回顾更新，完成历史不能改写 — 若时间投影错误可能漏提醒，B4/C5按版本及数据库时间回归。

- Ruling: 原生事件保存准确taxonomyHead，旧来源为null；00011新增列、HistoryEntry及新Study schema同步扩展 — Tree version ID不随知识归属移动变化，仅记录它不能定位当时配对归属；读取历史要保留该事实 — 若指针错误会错误解释历史归属，B4真实主题移动与C3旧来源回归校验。

- Ruling: 主题增减以本人第一次原生学习行为对应的配对目录为基线，只读比较当前知识集合，分类移动也计入增减；没有已知基线则提示当前总数而不虚构增减 — GET不能写last-seen，也不能逐用户发布扇出；需要UI注明“自开始学习以来” — 若基线规则不清楚会把累计增减误解为本次更新，B7词条和真实流程验证。

- Ruling: B4目标命令补充ReviewPreservesProgress和ReviewSearch前缀 — 计划指定的两个关键具名用例未被原Progress前缀实际匹配 — 若漏测可能错误完成率或泄露其他用户检索，按具名用例执行。

字典schemas/topic-labels.zh-CN.json保留来源URL、固定提交、原始文件摘要、当前英文名称快照摘要及修改说明，共6603条：63一级、534二级、4969具体、534其他、503辅助。75个公式/音译/范围差异对照官方英文核对，其中11个条目裁掉原目录没有的额外具名范围；8个中文中的TeX字面转义转为可读Unicode；534个其他类由对应父主题名明确标记。没有空值、未知占位或悬空TeX。既有63个中文一级名保留。

## 展示与搜索

服务端只在编号、类别和准确原英文同时匹配时使用字典。未来目录英文更改时不套用旧译名，以目录已有名称回退；独立测试目录同编号不同名称也不会套用真实资料。新增titleEn保留原title含义，新前端兼容旧响应；旧严格前端不识别新增字段，部署和回退必须沿用整组前后端切换。

中文检索先将直接命中节点的编号/英文/类别以参数化JSON传入查询，由当前目录实际核验后再扩展祖先，保留原英文检索、层级、分页和计数约束。不会改写知识正文、来源、备注或私人笔记。字典由二进制内嵌并核验固定摘要，部署无需本机路径。

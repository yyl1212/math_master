# 主题分类与归属发布操作说明

本阶段提供三级知识目录、知识点主题归属、冻结审核和成对发布。个人学习、笔记和旧模块退出属于后续阶段，不能把本阶段称为完整学习重构交付。服务启动不会自动迁移、导入或批准资料。

## 分类口径

主分类为63个一级主题、534个二级主题、4,969个具体主题。503个辅助类目和534个其他类目单列，完整目录共6,603个节点。知识点只能归属具体主主题；同一知识可以属于多个主题，祖先知识数量按稳定知识ID去重。分类目录条目不占每工作区100个知识、当前知识快照1,000个知识的原容量。

本地15个存储目录不等于网站主题。原schemaVersion=1正文、domainIds、topicIds、摘要、来源、批准与迁移00001—00009保持原字节；新增分类归属通过独立侧车保存。原16个板块链接显示人工映射的目标集合，不替代知识点的具体审核归属。

## 本地快照和转换

捕获工具只读本地资料，在读取前后检查文件身份、大小与摘要。一组四份MSC元数据必须来自同一正式、非staged批次；索引不一致的选中文件进入问题清单，不自动批准。来源覆盖、AI复核和作品家族统计只是来源事实，不能当作网站数学批准或个人学习完成。

使用`tools/topic-ingest/capture.mjs`的`captureTopicBatch`，指定资料根目录、私有输出目录及相对于Knowledge_JSON的主文件列表。需要比较批次时传入上一份清单路径。工具输出目录和文件分别使用700、600权限，不把整个资料库放入Git。

随后调用`buildCatalogueArchive(snapshotDir)`，生成包含6,603节点、来源记录索引、署名与许可的独立归一档案。只使用捕获副本，不读取持续变化的原文件。2026-10-07开发烟测采用本机实际131批，正式分类数量仍为上述口径；所选Manes文件205条记录没有精确MSC记录映射，因此没有虚构归属。

受保护维护环境中显式执行：

```sh
CGO_ENABLED=0 GOTOOLCHAIN=go1.27.1 go run ./cmd/topic-catalogue-import --archive /private/path/catalogue.json
```

在backend目录运行；DATABASE_URL由原受保护配置提供，不写入命令、日志或文档。命令最多读取32MiB普通文件，事务最多8秒，仅安装不可变批次和分类版本，输出版本标识，不改变公开head。

`normalizePrimaryFile`保留原编号、路径、页码、条件、证明范围、原始与语义摘要、来源及许可；软件capabilities单列为辅助信息。`buildDraftInputs`需要显式知识ID、类型、具体主题和作品家族映射，返回`{packages,issues}`。无法确定的映射、类型、条件或来源需人工处理；证明思路保留为sketch，不能升级为完整证明。

## 编辑和审核

1. 在内容工作区载入普通DraftInput或工具生成的topic-draft包。topic-draft中的正文与归属候选分别载入，不自动保存或送审。
2. 补齐数学正文与来源，保存内容后核对当前修订的每个知识点归属。一次控制请求最多8KiB，保存一个知识点；来源必须能匹配捕获记录及当前SourceMap。
3. 正文或来源改变会使对应归属待核对。无关单元编辑可以重新绑定未变的归属。保存失败保留输入，未保存主题选择、过期修订或缺项会阻止送审。
4. 送审将数学冻结正文与独立主题侧车保存在同一事务内，数学FrozenBody字节保持。审核关系检查同时核对冻结归属、来源和摘要；决定绑定同一归属摘要。
5. 普通作者不能审核自己的或继承作者的内容。管理员兼审核者按既有自审规则工作，当前资质在发布时再次核对；历史继承批准保留原依据。

## 发布和撤回

发布管理显示成对候选、主题新增/移出/归属变化和分页历史。首次允许公开空知识目录；旧已发布但未精确归类的知识仍可保留，不虚构主题归属。

准备绑定预期知识head、主题head和分类版本，激活在同一事务内再次核对两个head与冻结证据。任何一个head变化都要重新准备。仅调整分类时保留准确知识发布与数学SHA。近期密码核验只产生五分钟证明，核验成功后仍需单独点击激活，不自动重发命令。

主题head启用后，旧知识单独激活返回PUBLICATION_STALE。永久撤回沿用数学依赖闭包，在同一事务内生成过滤后的主题发布；历史归属、提交和批准不删除。结构或不可变触发器缺失/禁用时拒绝相关新操作，不用删标记、删历史或真实库down来恢复。

## 查询与验收

公开路径为`/api/v2/topics`、`/{id}`和`/{id}/knowledge`；页面为知识地图、`/topics/{id}`和旧板块导航集合。默认20、最多100条，检索最多512个UTF-8字节；重复、未知参数与任意代理路径拒绝。公开结果不含SourceRefs，匿名、SSR、预加载不产生个人学习记录。主题详情在服务端校验三个分页读取的PairRef一致，避免混合新旧发布。

后台归属、审核与成对发布沿用账户Cookie、CSRF、幂等键、8秒Go事务和1秒锁等待，前端十秒总预算包括账户预检。新后台重操作与旧内容服务共用两个验证槽；未知错误不输出数据库诊断。原冻结历史通过既有受保护入口读取。

开发回归只使用OpenVerified随机math_master_test_*库。满容量用例包含6,603分类节点及原最大1,000知识、4,000单元、200路线、1,000原创SVG/10MiB素材、32MiB正文，通过真实工作区、送审、审核和成对发布建立。查询预算8秒、响应2MiB，禁用不可变保护必须失败。

兼容门禁固定master基线bca91cc的2,184文件SHA及原API语义；新增路径精确列入白名单，变更按阶段保存目标SHA，策略本身另钉住SHA。旧保护仅在目标字节完全匹配时逆向比较原快照，不修改原基线。策略新增需要整分支审查，不能在验证时重算当前文件放行。

每阶段保留原回归并添加独立容量与双视口批次，单次Go五分钟、验证命令540秒、浏览器480秒。发布阶段MR保持草稿，不自动合并、部署或批量批准真实知识。
